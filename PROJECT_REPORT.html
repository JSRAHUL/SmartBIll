1. Introduction

In retail commerce, generating accurate invoices and managing inventory are critical everyday computational tasks. Traditional billing practices that involve manual calculations and handwritten slips frequently result in computational errors, inaccurate tax applications, lost transaction history, and accidental overselling when stock levels are depleted. To address these challenges, SmartBill is designed and developed as a comprehensive retail billing and stock management system implemented in Python.

The application seamlessly integrates product cataloguing, shopping cart management, automatic multi-tiered discounting, itemized Goods and Services Tax (GST) computation, payment processing, real-time inventory deduction, and sales analytics. The system is implemented using clean modular functions and relational persistence (JSON and SQLite), separating business logic from user interface operations.

The program incorporates defensive input validation and robust exception handling to ensure that non-numeric entries, negative numbers, invalid mobile numbers, and insufficient inventory attempts are handled gracefully without application crashes. These features demonstrate the practical application of foundational and intermediate Python programming principles in solving a real-world commercial problem.

2. Problem Statement

Design and develop a Bill Generator application using Python that generates a customer bill for purchased products. The program should allow users to enter product details, quantity, and price, calculate the total amount, apply GST (if applicable), and display a formatted bill. The system must prevent negative inventory, support item-level and bill-value discounts, handle multiple payment methods, and maintain persistent historical records.

3. Objectives

  • To develop a modular and interactive billing application using Python.
  • To maintain a persistent product catalogue containing product ID, name, category, price, stock, and GST rate.
  • To automatically retrieve product details and prices from the catalogue to eliminate manual cashier pricing errors.
  • To implement dual-tier discounts: item-level bulk quantity discounts and overall bill-value tiered discounts.
  • To calculate statutory GST accurately across varying tax slabs (5%, 12%, 18%) post-discount on the net taxable amount.
  • To implement real-time inventory synchronization by automatically decrementing stock upon successful payment.
  • To validate stock availability before purchase and prevent negative stock or overselling.
  • To calculate change due for cash payments and log digital payment methods (UPI, Card).
  • To record transaction history persistently and generate daily sales summaries and business analytics.

4. Project Description

SmartBill is structured as a modular Python billing application. When the program initiates, it verifies and loads the persistent product catalogue and invoice records. If launched for the first time, it automatically bootstraps the database with realistic sample items across multiple retail categories including Electronics, Groceries, Stationery, Beverages, and Personal Care.

The user is presented with an organized main menu comprising options: Create New Bill, Product Catalogue, Manage Inventory, Bill History, Sales Summary, Search Product, and Exit. During bill creation, the application captures customer details (Name and 10-digit Phone Number) and auto-generates a unique invoice number along with system date and time timestamps.

Cashiers add products to an active cart by specifying Product IDs. The system checks available shelf stock, enforces maximum quantity limits, and computes line subtotals. When checking out, the calculation engine evaluates item bulk discounts and store-wide bill offers, computes itemized GST on net taxable values, processes payments with exact change calculation, atomically updates inventory stock, and renders a professional receipt.

6. Algorithm

  1. Start the program and initialize data persistence files (products.json and bills.json / database.db).
  2. Display the SmartBill Main Menu with options: Create Bill, Product Catalogue, Inventory, Bill History, Sales Summary, Search, and Exit.
  3. Prompt the user to enter a menu choice (1–7).
  4. If Create New Bill is selected:
    1. Prompt for customer name and 10-digit mobile number.
    2. Generate a unique invoice number, system date, and system time.
    3. Prompt for Product ID and search the catalogue. If not found or out of stock, notify the user.
    4. Prompt for quantity; verify that requested_quantity ≤ available_stock.
    5. Add item to cart and calculate item subtotal. Allow cashier to add more items, modify quantities, or remove items.
    6. When proceeding to checkout, compute item quantity discounts and overall bill-tier discounts.
    7. Distribute bill discounts proportionally across line items to calculate line-level taxable values.
    8. Compute GST per item based on its category GST rate (5%, 12%, 18%) and sum to find total GST.
    9. Calculate Grand Total: Grand Total = Net Taxable Value + Total GST.
    10. Prompt for payment method (Cash, UPI, Card). If Cash, input tender and compute Change Due = Tender − Grand Total.
    11. Atomically deduct purchased quantities from catalogue stock.
    12. Save the invoice record to persistent storage and print the formatted receipt.
  5. If Product Catalogue is selected: Allow viewing all items, adding new products, modifying prices/stock, or deleting products.
  6. If Manage Inventory is selected: Display stock levels, highlight low-stock items (≤ threshold), and allow quick restocking.
  7. If Bill History is selected: Display historical transaction summaries and permit receipt reprinting.
  8. If Sales Summary is selected: Aggregate total sales revenue, total GST collected, total discounts given, and top-selling products.
  9. If Search Product is selected: Perform case-insensitive substring search by product name, category, or ID.
  10. If Exit is selected: Display exit message and terminate program safely.

022def calculate_item_quantity_discount(price, qty):
023    """Apply item-level bulk purchase discount."""
024    subtotal = price * qty
025    if qty >= 10:
026        rate = 10.0
027    elif qty >= 5:
028        rate = 5.0
029    else:
030        rate = 0.0
031    discount_amt = round(subtotal * (rate / 100.0), 2)
032    return rate, discount_amt
033
034def calculate_bill_tier_discount(net_subtotal):
035    """Apply tiered store-wide basket discount."""
036    if net_subtotal >= 5000:
037        rate = 15.0
038    elif net_subtotal >= 3000:
039        rate = 10.0
040    elif net_subtotal >= 1000:
041        rate = 5.0
042    else:
043        rate = 0.0
044    discount_amt = round(net_subtotal * (rate / 100.0), 2)
045    return rate, discount_amt

Program Listing — Financial Computation & Multi-Slab GST Calculation
046def compute_bill_financials(cart):
047    """Calculates gross subtotal, discounts, taxable value, GST, and grand total."""
048    gross_subtotal = 0.0
049    total_qty_discount = 0.0
050    line_details = []
051
052    # Step 1: Compute item-level gross and quantity discounts
053    for item in cart:
054        line_gross = round(item["price"] * item["qty"], 2)
055        q_rate, q_disc = calculate_item_quantity_discount(item["price"], item["qty"])
056        line_after = line_gross - q_disc
057        gross_subtotal += line_gross
058        total_qty_discount += q_disc
059        line_details.append({"item": item, "gross": line_gross, "after": line_after, "disc": q_disc})
060
061    net_after_qty = gross_subtotal - total_qty_discount
062    b_rate, b_disc = calculate_bill_tier_discount(net_after_qty)
063    total_discount = round(total_qty_discount + b_disc, 2)
064    overall_taxable = round(gross_subtotal - total_discount, 2)
065
066    # Step 2: Proportional allocation of bill discount to compute itemized GST
067    total_gst = 0.0
068    processed_items = []
069    for line in line_details:
070        itm = line["item"]
071        share = round(b_disc * (line["after"] / net_after_qty), 2) if net_after_qty > 0 else 0.0
072        taxable = max(0.0, round(line["after"] - share, 2))
073        gst_amt = round(taxable * (itm["gst_rate"] / 100.0), 2)
074        total_gst += gst_amt
075        processed_items.append({
076            "id": itm["id"], "name": itm["name"], "price": itm["price"],
077            "qty": itm["qty"], "taxable": taxable, "gst_rate": itm["gst_rate"],
078            "gst_amt": gst_amt, "item_total": round(taxable + gst_amt, 2)
079        })
080
081    grand_total = round(overall_taxable + total_gst, 2)
082    return {
083        "subtotal": gross_subtotal, "qty_discount": total_qty_discount,
084        "bill_discount": b_disc, "total_discount": total_discount,
085        "taxable": overall_taxable, "gst": round(total_gst, 2),
086        "grand_total": grand_total, "items": processed_items
087    }
